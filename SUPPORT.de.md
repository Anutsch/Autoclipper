# Autoclipper unterstützen

[English](SUPPORT.md) · [Deutsch](SUPPORT.de.md) · [Español](SUPPORT.es.md)

Autoclipper ist kostenlos. Wenn dir das Tool beim Schneiden von Twitch-Clips Zeit spart, kannst du die Entwicklung mit einem freiwilligen Beitrag unterstützen. Damit hilfst du mir, neue Versionen zu testen, Fehler zu beheben und die Installation zu vereinfachen.

[Autoclipper auf Ko-fi unterstützen](https://ko-fi.com/anutsch)

Hilfe beim Einstieg findest du in der [Installationsanleitung](README.de.md#installation-aus-dem-github-download). Gib bei einer Fehlermeldung dein Betriebssystem, die Autoclipper-Version und die Schritte an, mit denen sich der Fehler nachstellen lässt.

[Fehler auf GitHub melden](https://github.com/Anutsch/Autoclipper/issues/new)
