# Componentes de la beta de Windows

- CPython 3.12.16 de [Python Build Standalone, Release 20261026](https://github.com/astral-sh/python-build-standalone/releases/tag/20261026). Los avisos de licencia están en la carpeta de Python.
- FFmpeg. Compilación LGPL con enlace dinámico de [BtbN FFmpeg Builds](https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-11-10-12-39), con avisos en la carpeta `ffmpeg`. [Código fuente de esta compilación de FFmpeg](https://github.com/FFmpeg/FFmpeg/tree/d4070a14ce) · [Scripts de compilación](https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-11-10-12-39). Autoclipper ejecuta FFmpeg como un programa independiente.
- [Send2Trash 1.8.3](https://pypi.org/project/Send2Trash/1.8.3/) con avisos de licencia en `vendor`.
- OpenCV 4.11 y NumPy 2.2 para la detección local de caras. Los avisos de licencia acompañan a los paquetes en `vendor`.
