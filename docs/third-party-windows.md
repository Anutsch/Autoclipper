# Windows beta components

- CPython 3.12.16 from [Python Build Standalone, Release 20261026](https://github.com/astral-sh/python-build-standalone/releases/tag/20261026). Licence notices are included in the Python folder.
- FFmpeg. Dynamically linked LGPL build from [BtbN FFmpeg Builds](https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-11-10-12-39), with notices in the `ffmpeg` folder. [Source code for this FFmpeg build](https://github.com/FFmpeg/FFmpeg/tree/d4070a14ce) · [Build scripts](https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-11-10-12-39). Autoclipper runs FFmpeg as a separate program.
- [Send2Trash 1.8.3](https://pypi.org/project/Send2Trash/1.8.3/) with licence notices in `vendor`.
- OpenCV 4.11 and NumPy 2.2 for local face detection. Their licence notices are included with the packages in `vendor`.
