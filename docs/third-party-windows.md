# Komponenten der Windows-Beta

- CPython 3.12.16 aus [Python Build Standalone, Release 20261026](https://github.com/astral-sh/python-build-standalone/releases/tag/20261026). Lizenzhinweise liegen im Python-Ordner.
- FFmpeg, dynamisch gelinkter LGPL-Build aus [BtbN FFmpeg Builds](https://github.com/BtbN/FFmpeg-Builds/releases/tag/autobuild-2026-11-10-12-39), inklusive der mitgelieferten Hinweise im Ordner `ffmpeg`. [FFmpeg-Quellcode dieses Builds](https://github.com/FFmpeg/FFmpeg/tree/d4070a14ce) und [Build-Skripte](https://github.com/BtbN/FFmpeg-Builds/tree/autobuild-2026-11-10-12-39). FFmpeg wird als separates Programm aufgerufen.
- [Send2Trash 1.8.3](https://pypi.org/project/Send2Trash/1.8.3/) mit Lizenzhinweisen unter `vendor`.
