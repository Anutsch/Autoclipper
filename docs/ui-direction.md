# Midnight Control — kompakte Regie

Streams stehen in einer vertikalen Liste. Jede Zeile verwendet ein Drittel für Profil, Namen und Statussymbol sowie zwei Drittel für das Twitch-Vorschaubild. Vorschauen sind aktualisierte Standbilder. Auswahl und Clip-Import sind in Chrome und der Mac-App verfügbar.

Ein Aktivitätsknopf öffnet eine kompakte Liste mit Details und Abbruch. Die nummerierte Pipeline entfällt. Statusdetails erscheinen als Tooltip oder im Aktivitätsmenü. Das Statussymbol öffnet den bestehenden Stream-Tab.
