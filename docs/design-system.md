# Midnight Control

Systemschrift, fast schwarzes Nachtblau (#04050a), violette Akzente (#c5afe8), entsättigtes Grün für bereit/fertig, Bernstein für Werbung, Rosa für Probleme. Text auf Glas bleibt deckend.

Stream-Zeilen: 1:2-Spalten, 12px Radius, 10px Abstand. Statusfarben werden durch unterschiedliche Zeichen und zugängliche Beschriftungen ergänzt. Werberestzeit bleibt sichtbar.

Aktivitätsring: passende Phasensymbole, bestimmter Fortschritt nur bei bekannter Downloadgröße; sonst unbestimmte Drehung. Reduzierte Bewegung wird berücksichtigt. Details-Menü unterstützt Tastatur, Escape und Schließen per Außenklick.
